# Internal Developer Portal (IDP)

The Internal Developer Portal provides a single pane of glass for service ownership and platform operations.

## Typical capabilities

- Service catalogue and ownership metadata
- API specification visibility
- Deployment and environment status
- Links to runbooks, dashboards, and repositories

## Implementation approach

- Built with open-source foundations such as Backstage
- Integrated with GitHub repositories and workflows
- Extended with platform-specific plugins and policies
